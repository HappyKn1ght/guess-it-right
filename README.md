# 🎯 Number Guessing Game (Python CLI)

A command-line Number Guessing Game built in Python. Created to practice the `random` module, nested `while` loops, `try / except` input validation, and attempt tracking.

## ✨ Features
- **Randomized Target:** Generates a secret number between `1` and `100` each round.
- **Smart Hints:** Guides players with `"Guess Higher!"` and `"Guess Lower!"` feedback.
- **Input Validation:** Handles non-numeric inputs (`ValueError`) and out-of-range numbers (`< 1` or `> 100`) without crashing or wasting attempts.
- **Attempt Counter & Replay Loop:** Tracks total valid guesses per round and lets players replay seamlessly.

## 🚀 How to Run
1. **Clone the repository:**
   ```bash
   git clone https://github.com/HappyKn1ght/guess-it-right
   ```
2. **Navigate into the project folder:**
   ```bash
   cd number-guessing-game
   ```
3. **Run the game:**
   ```bash
   python main.py
   ```
